How this works

Ask a question about the category — who is running what, how a claim is phrased, how many advertisers use it — or describe something you want to make. The agent searches before it answers, and shows you every search it ran.

Counts come from the whole corpus, not from a sample, so "how many" and "who does it most" are exact. For ideas, it checks what Trilith has already published and tells you when a topic is covered and what the genuinely new angle is instead.

This page needs the Worker deployed and its URL set in ideas.html.

  1. cd worker && npm install
  2. npx wrangler secret put ANTHROPIC_API_KEY
  3. npx wrangler secret put SUPABASE_ANON_KEY — the anon key, never the service role key
  4. npx wrangler deploy
  5. Put the deployed URL into WORKER_URL at the top of the script in ideas.html, then commit

Answers are grounded in the tracked corpora only. Enter sends; Shift+Enter adds a line.
